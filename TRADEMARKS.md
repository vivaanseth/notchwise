# Names and branding

Notchwise is an independent project by Vivaan. Its source code is licensed under
GPL-3.0-or-later; see [LICENSE](LICENSE).

## Vorssaint

Notchwise is built on [Vorssaint](https://github.com/vorssaint/vorssaint-utils),
also licensed under GPL-3.0-or-later. The GPL lets this project use and change
Vorssaint's source code, but it does not grant use of the Vorssaint name, logo or
branding. Notchwise therefore uses its own name and is not affiliated with or
endorsed by Vorssaint. Vorssaint's copyright notices stay on the files that came
from it, as the license requires. Some internal names (the executable, the bundle
identifier `com.vorssaint.voiceos`, type and file names) still carry its name for
compatibility and are not used as branding.

## VoiceOS

The assistant's design is inspired by VoiceOS. Notchwise is not affiliated with,
endorsed by or connected to VoiceOS or its makers. Internal source folders and
type prefixes (`VoiceOS/`, `VO…`) are code names only.
